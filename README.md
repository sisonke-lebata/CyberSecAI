# CyberSec Security Assistant

A WPF-based interactive cybersecurity chatbot that helps users understand security best practices, threat prevention, and protective measures

## Features

- Real-time Chat Interface with modern dark theme
- Typing Effect for realistic bot responses
- Security Topics Coverage:
  - Password security best practices
  - Phishing attack prevention
  - Malware protection
  - Firewall configuration
  - Two-Factor Authentication (2FA)
  - VPN usage guidelines
  - Data backup strategies
  - Software update importance
- Conversation Memory for follow-up questions
- Keyboard Shortcuts: Enter to send, Shift+Enter for new lines

## Prerequisites

- .NET 8.0 SDK or later
- Windows OS (WPF application)
- Visual Studio 2022 (recommended)

## Installation

1. Clone this repository
2. Open CyberSecGUI.sln in Visual Studio
3. Build the solution (Ctrl+Shift+B)
4. Run the application (F5)
